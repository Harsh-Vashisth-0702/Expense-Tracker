# Python Expense Tracker

A beginner-friendly expense tracker built using Python.

## Features

- Add expenses
- View all expenses
- View today's expenses
- View weekly expenses
- View monthly expenses
- View yearly expenses
- Category-wise spending summary
- Total spending
- Input validation
- JSON data storage

## Technologies Used

- Python
- JSON

## Project Structure

- `main.py` - Main program and menu
- `expense.py` - Expense creation and input validation
- `storage.py` - Saving and loading expenses
- `reports.py` - Expense reports and calculations
- `expenses.json` - Local expense data (not uploaded to GitHub)

## How to Run

Run:

```bash
python main.py
